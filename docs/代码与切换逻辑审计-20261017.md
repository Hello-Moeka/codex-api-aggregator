# 代码与切换逻辑审计

日期：2026-10-17。范围：开源代码的路由器、控制面板测试路径、状态显示、持久化与 Docker 部署配置。独立使用说明见同目录 `切换逻辑说明.md`。

## 已修复发现

| 级别 | 问题及触发条件 | 修复 |
| --- | --- | --- |
| 高 | 恢复探测采用简化解析，可能把无效流判断为恢复 | 复用业务请求协议解析、错误分类和期限，探测内容写入空接收器 |
| 高 | 正常官方额度查询清除普通请求失败次数，可能使错误始终达不到熔断阈值 | 额度保护独立维护，只解除额度状态，不清除其他故障 |
| 高 | 并发旧请求成功覆盖新故障或覆盖较新会话绑定 | 故障 revision 和请求发起时间共同保护状态与绑定 |
| 高 | 普通失败未达熔断阈值后，粘性会话可能使旧来源无法得到恢复验证 | 官方与中转均约 30 秒后安排后台检查，再经两次成功确认；中转主动回迁继续受观察期约束 |
| 中 | SSE 曾在首个有效事件后放过畸形事件，或错误协议结构抛出非预期异常 | 逐事件校验类型、嵌套结构和失败状态；非流式官方错误沿用官方分类 |
| 中 | Chat 已完成但上游不关闭连接，造成误超时 | 所有请求的 choice 完成即结束并补 DONE，不继续等待断开 |
| 中 | 恢复后残留旧滚动失败历史，容易再次熔断 | 完成两次成功恢复后清除对应历史 |
| 中 | 历史回迁标记使未来任意一次失败永久触发立即熔断 | 惩罚限定于未通过的观察期或实际回迁后 30 分钟 |
| 中 | 官方候选暂停、额度未知或模型故障时，仍压住低价中转回迁 | 官方接管候选增加启用、额度及模型状态筛选，实际请求仍二次校验 |
| 中 | 内部异常被表示成通用上游不可用 | 返回固定 internal_router_error/500，避免误诊供应商，避免暴露异常正文 |
| 低 | 手动测试不识别无空格 data:，且 completed 后仍可能等待 | 支持紧凑 SSE，完成事件后立即停止读取 |
| 低 | 非有限 Retry-After 或畸形可选 usage 字段导致错误 | 非有限等待值使用默认值；日志防御非字典 usage/details |
| 低 | 独立 quota_blocked 在界面未优先显示 | 显示等待额度恢复，避免额度与熔断叠加时误导 |
| 中 | 中转推理 API 的余额错误可能被误判为来源级余额耗尽，恢复探测沿用触发故障的模型 | 余额只认独立查询；推理余额错误按模型级不可用隔离，恢复探测默认优先 gpt-6.1-sol |

高/中/低为本次对可用性和状态正确性的影响分级，不是第三方漏洞评分。

## 保留的设计限制与未验证范围

- 会话与 response ID 映射不持久化，路由器重启会丢失；调用方需要能发送完整历史。
- 10% 预留是查询快照控制，不能严格保证并发及大请求永不越线。
- 官方恢复仅接管当前使用中转站的会话，健康 Plus B 不会主动被 Plus A 抢占。
- 恢复探测验证单个模型的短文本流，不等于全部模型、长推理与所有工具均可用。
- 回迁失败后提高的观察期当前保持，不会自动衰减回默认值。
- SQLite 同步写入处于异步请求路径；本轮未做大并发压测或磁盘故障注入。
- 未完整审计外部 CLIProxyAPI 二进制内部实现，未扫描所有依赖 CVE，未保证供应商的实际计费、模型能力或未来协议兼容性。
- 面板检查了回环绑定、Host/Origin/CSRF 限制；本轮未做浏览器渗透测试，也未从其他局域网设备重新验证入站连接。
